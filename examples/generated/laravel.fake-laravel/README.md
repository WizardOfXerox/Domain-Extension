# Laravel Template

Quick start:
1. Create Laravel project (if needed):
   - `composer create-project laravel/laravel laravel`
2. Enter project:
   - `cd laravel`
3. Start dev server:
   - `php artisan serve --host 127.0.0.1 --port 8000`
4. Domain Extension backend origin:
   - `http://127.0.0.1:8000`
5. Open:
   - `https://laravel.fake/`

Optional websocket notes:
- Default pack wsPath is `/app` (for Echo/socket setups if used).
