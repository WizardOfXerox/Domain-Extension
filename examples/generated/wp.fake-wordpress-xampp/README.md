# WordPress XAMPP Template

Target project folder:
- `C:\xampp\htdocs\wp`

Suggested steps:
1. Download WordPress and extract to that folder.
2. Start Apache + MySQL in XAMPP.
3. Complete WordPress installer at:
   - `http://127.0.0.1/wp/`
4. Use Domain Extension Local mode for:
   - `https://wp.fake/`

Configured backend origin:
- `http://127.0.0.1/wordpress`
